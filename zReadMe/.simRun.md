# Simulation Run Commands

All commands run from the monorepo root (`dapp-mvp-boilerplate/`).

## CLI Format

`npm run contracts:simulate -- <scenario> <seed> --deploy [--steps N] [--headless] [--charts|--no-charts]`

- `<scenario>`: scenario key from the list below
- `<seed>`: deterministic seed (default `12345`)
- `--deploy`: required (deploys fresh local contracts)
- `--steps N`: currently ignored (all runs are fixed at `2000` steps)
- `--headless`: less console logging
- `--charts` / `--no-charts`: toggle chart generation

Results are saved to:
- `apps/contracts/simulation-results/<scenario>_<seed>_<timestamp>/`
- `apps/contracts/simulation-results/latest.json` (this is what dashboard `/latest` reads)

## Quick Run

`npm run contracts:simulate:quick`

Equivalent to: `normal`, seed `12345`, `--deploy`, `--steps 2000`.

## Scenarios

### Normal Market (2,000 steps)
`npm run contracts:simulate -- normal 12345 --deploy`

### Bull Run (2,000 steps)
`npm run contracts:simulate -- bullRun 12345 --deploy`

### Bear Market (2,000 steps)
`npm run contracts:simulate -- bearMarket 12345 --deploy`

Alias also supported:
`npm run contracts:simulate -- bearRun 12345 --deploy`

### Volatility Shock (2,000 steps)
`npm run contracts:simulate -- volatilityShock 12345 --deploy`

### Black Swan Random (2,000 steps)
`npm run contracts:simulate -- blackSwan 12345 --deploy`

### Black Swan Down / Crash (2,000 steps)
`npm run contracts:simulate -- blackSwanDown 12345 --deploy`

### Black Swan Up / Melt-up (2,000 steps)
`npm run contracts:simulate -- blackSwanUp 12345 --deploy`

### Liquidity Crisis (2,000 steps)
`npm run contracts:simulate -- liquidityCrisis 12345 --deploy`

### Liquidation Cascade (2,000 steps)
`npm run contracts:simulate -- liquidationCascade 12345 --deploy`

### Oracle Failure (2,000 steps)
`npm run contracts:simulate -- oracleFailure 12345 --deploy`

## Useful Variations

Different deterministic trajectory (same scenario):
`npm run contracts:simulate -- normal 99999 --deploy`

Short smoke test:
`npm run contracts:simulate -- blackSwan 12345 --deploy --steps 500`

Low-noise run:
`npm run contracts:simulate -- liquidationCascade 12345 --deploy --headless`
